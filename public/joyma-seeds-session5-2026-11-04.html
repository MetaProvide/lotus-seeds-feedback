A quick update · decided on 20 October

Event types, categories and tags

How your program is organised, so participants can browse it and filter a calendar. Thank you, Nina, for sharing Thubten Norbu Ling’s tags: they shaped this.

Shared across the network

Categories and tags are the same for every center, so search and the calendar work everywhere. You will be able to request a new tag.

A retreat is a type of event

Retreats are an event type, like a class or a course, not a category. The category list says what the teaching is about.

Study programmes · later

On the longer-term roadmap. Programmes will get their own place, with order and optional parts across events and Study spaces. Official FPMT programmes carry a badge; your own programmes sit alongside them.

Event types, categories and tags are built next, with design input, together with the calendar view
